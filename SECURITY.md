# Security Policy

## Supported Version

Security fixes are applied to the latest released version of OpenModel Preview.

## Reporting a Vulnerability

Use GitHub's private vulnerability reporting for this repository. Please include:

- affected plugin version and JetBrains IDE build;
- model format and a minimal reproducible sample when it can be shared safely;
- expected and observed behavior;
- security impact and reproduction steps.

Do not include private models, source files, credentials, signing keys, or Marketplace tokens in a public issue.

For ordinary bugs without sensitive details, use the public issue tracker.
