# Changelog

## 0.1.0 - 2026-11-07

- Add local OpenSCAD preview backed by the installed OpenSCAD CLI.
- Add ASCII and binary STL parsing.
- Add OBJ polygon triangulation with positive and negative indices.
- Add ASCII, binary little-endian, and binary big-endian PLY parsing.
- Add an offline JCEF/WebGL viewer with orbit, zoom, fit, and grid controls.
